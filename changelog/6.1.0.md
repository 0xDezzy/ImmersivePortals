# Immersive Portals - CE 6.1.0

Minecraft 1.21.1 / NeoForge 21.1.228+ / Java 21

## Stationary miniature base prototype

- Add `/portal miniature create/list/pickup/place/restore` for permission-level-2 players. Only the creator can change a registered view.
- Wrap an existing, full-size building region with six bidirectional portal faces. Fractional scale divisors from 2 to 32 are supported, with bounded region/exterior sizes and a 32-view server cap.
- Keep original blocks, inventories, machines and occupants at their existing backing coordinates. Pickup removes the view but keeps its backing reference; restoration removes the view/reference without deleting backing contents. Entity scale remains unchanged on entry and exit.
- Reconcile derived portal faces after reload and quarantine unsupported/unreadable registry data rather than replacing it with an empty registry.
- Preserve global destination chunk loaders with many nearby miniature faces.

This is an **opt-in, operator-only prototype**, not the completed tiny-airship feature. There is no craftable/breakable anchor, automatic relocation into an allocated backing region, automatic occupant resizing, or moving Sable miniature. CE's scaling-portal rejection for Sable structures is unchanged. [Issue #24](https://github.com/UpperMoon0/ImmersivePortals/issues/24) remains open for the remaining milestones.

Read the [workflow, lifecycle and limitations](../docs/miniature-bases.md) before using the commands. Keep world backups. Shrinking a view does not reduce the building's simulation cost or certify every modded machine.
